# Aury Shop — Asistente ML

Bot de atención al cliente con IA para Aury Shop en Mercado Libre México.

## Configuración en Render

1. Crear nuevo Web Service en render.com
2. Conectar este repositorio
3. Agregar variable de entorno: `ANTHROPIC_API_KEY`
4. Deploy automático

## Uso

Abre la URL del servicio en tu celular e instálala como PWA.
